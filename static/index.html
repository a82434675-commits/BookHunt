About Us

BookHunt is a simple, self-hosted platform for storing, organizing, and searching your PDF documents — built for students, teachers, and anyone who works with a lot of study material.

Here's everything BookHunt lets you do:

Upload PDFs
Add any PDF file to your personal library and give it a name of your choice, so it's easy to recognize later.

Organize your library
Every file you upload appears in one clean list, along with the date it was added and its file size, so you always know what you have and when it was added.

Rename files
Changed your mind about a file's name? Rename it anytime without needing to re-upload the file.

Replace a file
Need to update a document with a newer version? Replace the old file with a new one while keeping the same entry.

View and download
Open any uploaded PDF directly in your browser, or download it, with a single click.

Delete files
Remove any file you no longer need, permanently and instantly.

Search inside your PDFs
Type in a keyword or question, and BookHunt will scan through the text of your PDF and show you the exact passages where that word appears — no more manually scrolling through long documents.

Search across your entire library
Not sure which file has the information you need? Search all of your uploaded PDFs at once, and BookHunt will tell you which files contain matches and show you the relevant snippets.

Duplicate protection
BookHunt automatically checks if a file with the same name already exists, and also checks if the exact same file has already been uploaded under a different name — so your library stays clean and free of duplicates.

BookHunt is designed to be simple and fast: no clutter, no unnecessary steps, just a clean way to keep your documents organized and searchable in one place.
